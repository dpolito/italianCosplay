# CRONACHE COSPLAY

Use this skill when the user asks for a prompt or concept for a `CRONACHE COSPLAY` image.

The goal is to generate a reusable prompt base for square 1:1 social graphics with:

- ultra-realistic editorial photography
- fake breaking-news presentation
- humorous cosplay exaggeration
- clear, readable typography
- a serious scientific or investigative tone

Keep the core style stable, but let the headline text, on-image copy, and scene details change per request.

## Prompt Base

Use this as the default structure and replace the bracketed parts with the requested topic:

```text
Square 1:1 social media graphic, ultra-realistic editorial photography, premium Facebook viral meme style, designed for maximum engagement.

Create a fake satirical news image for the recurring series "CRONACHE COSPLAY".

[SCENE DESCRIPTION]

Graphic layout

At the very top create a premium red breaking-news banner.

Left side:
[LEFT LABEL]

Right side:
[RIGHT LABEL]

Below, in huge bold typography:
[MAIN HEADLINE]

Under it:
[SUBHEAD]

Typography must be perfectly readable, centered, bold, white and yellow on a dark red banner, clean editorial newspaper design.

Visual storytelling

Make the joke immediately obvious through a visual contradiction between a serious news/science frame and an absurd cosplay reality.

Include humorous details such as:
[HUMOR DETAILS]

Style

Ultra realistic photography, cinematic lighting, premium editorial magazine quality, expressive faces, humorous but believable, vibrant colors, shallow depth of field.

Negative prompt

No copyrighted characters, no anime characters, no Marvel, no DC, no Disney, no Pokémon, no logos, no brand names, no watermark, no AI artifacts, no unreadable text, no distorted hands, no extra fingers.
```

## Writing Rules

- Keep the layout editorial and premium, not cartoonish.
- Make the joke readable in one glance.
- Preserve the fake scientific/news tone unless the user asks for a different framing.
- If the user supplies exact copy, keep it unchanged.
- If the user only gives a topic, invent the headline and subhead in Italian, consistent with the series tone.
