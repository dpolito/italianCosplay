# ItalianCosplay Content Skill

## Purpose

This skill defines rules for managing editorial content on ItalianCosplay.it.

The blog is a strategic component of the platform. Content must support:

- organic traffic growth
- cosplay community value
- event discovery
- SEO authority
- future monetization

Articles are not isolated pages. They are part of a connected content ecosystem.

---

## Content Philosophy

Every article should have a purpose.

Before creating content evaluate:

1. Who is the target user?
2. What search intent does it satisfy?
3. Can it generate organic traffic?
4. Can it connect users to events or services?
5. Can it remain useful over time?

Avoid publishing content only to increase article count.

---

## Content Types

ItalianCosplay content can include:

### Evergreen Guides

Long-term useful content. Examples: how to start cosplay, cosplay makeup guides, costume creation tutorials.

### Event Content

Related to upcoming events, event announcements, event previews, event reports.

### News Content

Examples: guests, announcements, competitions, industry news.

### Community Content

Examples: interviews, cosplay stories, creator profiles.

### Commercial Content

Examples: sponsored articles, organizer promotions, partner content.

Commercial content must be clearly identified.

A pillar article:

- links to detailed articles
- receives internal links
- remains updated


## Search Intent

Every article should match user intent.

**Informational** — user wants knowledge. Example: *"Come fare un cosplay"*

**Transactional** — user wants an action. Example: *"Dove comprare materiali cosplay"*

**Navigational** — user wants a specific destination. Example: *"Lucca Comics cosplay"*

---

## Article Quality

Articles should provide:

- useful information
- original value
- clear structure
- reliable information

Avoid: generic AI summaries, duplicated text, keyword stuffing.

---

## Article Structure

Blog articles should follow a consistent structure.

Recommended format:

```
Title
Introduction
Main sections
Images
Related content
FAQ when useful
Conclusion
```

### Article Title

Titles must:

- describe the content
- match search intent
- be attractive to users

Avoid: clickbait, misleading titles, keyword repetition.

**Good:** `Come creare una parrucca cosplay: guida completa`

**Bad:** `Parrucca cosplay migliore incredibile guida cosplay parrucca`

### Introduction

The introduction should explain the topic, answer the user's need, and encourage reading.

Avoid long generic introductions.

### Heading Structure

Articles must use semantic headings.

```html
<h1>Article title</h1>
<h2>Main topic</h2>
<h3>Subtopic</h3>
```

Rules: one H1 only, logical hierarchy, headings describe sections.

### Article Length

Length should depend on topic. Do not write long content only to increase word count.

Prefer: complete answers, useful examples, practical information.

---

## Blog SEO Metadata

Every article should have: SEO title, meta description, slug, excerpt, canonical URL.

### Blog Slug

Slugs must be lowercase, readable, stable, keyword relevant.

**Good:** `come-iniziare-a-fare-cosplay`

**Avoid:** `post-123`

### Blog Images

Articles should use optimized images.

Requirements: WebP when possible, descriptive filenames, alt text, correct dimensions.

Example: `trucco-cosplay-special-effects.webp`

### Featured Image

Every important article should have a featured image, used for article cards, social sharing, Open Graph, and search previews.

---

## Internal Linking Strategy

Internal links are mandatory.

Articles should connect: related guides, events, categories, relevant pages.

### Event Integration

The blog must support event discovery.

Example: an article *"Come prepararsi a Lucca Comics"* should link to the Lucca Comics & Games event page.

### Event Page Integration

Event pages should link back to relevant articles.

Example: the event page for *Lucca Comics 2026* can include cosplay preparation guides, previous editions, related news.

### Related Content

Every article should consider related content blocks.

Example:

```
Potrebbe interessarti:
- guide cosplay
- eventi vicini
- articoli simili
```

---

## FAQ Sections

FAQ sections can be added when useful.

**Good FAQ:** *"Come posso iniziare a fare cosplay?"* with a real answer.

Avoid artificial FAQ sections created only for SEO.

### FAQ Schema

Use FAQ Schema only when:

- questions are visible
- answers are complete
- content is useful

Never add hidden FAQ markup.

---

## Content Updates

Important articles should be reviewed over time.

Update: outdated information, broken links, expired dates, missing references.

Use `datePublished` and `dateModified`.

---

## Editorial Workflow

Content should follow a workflow.

```
Idea → Draft → Review → SEO Optimization → Published → Updated
```

### Scheduled Publishing

The system can support scheduled articles.

Possible states: `draft`, `scheduled`, `published`, `archived`.

Publishing should be handled automatically when required.

---

## AI Assisted Content

AI tools can assist content production. However, every article must provide human value.

AI generated content must be:

- reviewed
- corrected
- enriched
- fact checked

### AI Content Rules

Avoid:

- automatic mass publishing
- generic articles
- repeated structures
- low-value summaries

Prefer:

- expert improvements
- practical examples
- original insights
- community-oriented information

## Content Performance

Measure content effectiveness.

Useful metrics: organic traffic, impressions, clicks, CTR, average position, page views, time on page, internal link clicks.

### Content Analytics

Analytics should help answer:

- Which topics attract users?
- Which articles generate event visits?
- Which content should be updated?
- Which clusters are growing?

---

## Content Monetization

Content can support future business models.

Possible opportunities: sponsored articles, partner content, featured guides, organizer promotions.

Commercial content must:

- be transparent
- maintain quality
- not damage user trust

### Sponsored Content Rules

Sponsored articles should:

- provide value
- be clearly identified
- follow SEO guidelines
- avoid misleading users

Do not publish low-quality paid content.

### Content and Advertising Relationship

Content and advertising must coexist. Advertising should not reduce readability, damage UX, or compromise editorial credibility.

---

## Content Accessibility

Articles should be readable for everyone.

Consider: short paragraphs, clear headings, descriptive links, accessible images.

Avoid: huge text blocks, poor contrast, unnecessary complexity.

---

## Content URLs

Public article URLs should be stable.

**Good:** `/blog/come-iniziare-a-fare-cosplay`

**Avoid:** `/blog/post?id=123`

---

## Content Security

Editorial systems must protect: drafts, unpublished content, author permissions, media uploads.

Only authorized users can publish, edit, or delete content.

---

## Blog Administration

Backoffice should support:

- create article
- edit article
- categories
- tags when useful
- scheduling
- images
- SEO fields
- preview

---

## Content Anti-Patterns

Avoid the following.

### Keyword Stuffing

Repeating keywords unnaturally.

### Duplicate Articles

Creating multiple pages with the same intent.

### Thin Content

Publishing pages with little useful information.

### Uncontrolled AI Content

Publishing AI text without review.

---

## Content Checklist

Before publishing verify:

### SEO

- Is the title optimized?
- Is metadata complete?
- Is the URL friendly?
- Are internal links present?

### Quality

- Does it answer the user's question?
- Is information accurate?
- Does it provide unique value?

### Technical

- Is Schema.org correct?
- Are images optimized?
- Is canonical correct?

### Business

- Can it support event discovery?
- Can it contribute to future monetization?
